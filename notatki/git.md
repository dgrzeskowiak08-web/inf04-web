# Sciaga z komend Git

- \git init\: Tworzy nowe, puste repozytorium Git w biezacym katalogu.
- \git config\: Ustawia dane konfiguracji, np. nazwe uzytkownika i email.

- \git status\: Pokazuje stan plikow (zmodyfikowane, dodane do poczekalni, niesledzone).
- \git add\: Dodaje pliki do poczekalni (staging area) przed commitem.
